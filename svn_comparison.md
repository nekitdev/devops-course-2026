# Сравнение Git и SVN

## Почему в Git ветвление "дешевое", а в SVN — "дорогое"?

В Git ветка — файл с указателем на коммит, поэтому ее создание происходит почти моментально.
В SVN ветка — каталог в репозитории, поэтому ее создание требует компирования всех файлов и истории,
что занимает значительное время и ресурсы, особенно в больших репозиториях.

## Можно ли в SVN сделать коммит без интернета? Почему?

Нет, ведь коммит в SVN отправляется на сервер, поэтому для выполнения коммита требуется
подключение к интернету. В Git коммит создается локально, для него не нужно подключение к сети.

## В каких сценариях SVN до сих пор может быть предпочтительнее Git?

SVN выигрывает в случаях с большим количеством бинарных файлов и там, где нужны
блокировки файлов, которые нельзя слить. Также SVN лучше подходит для централизованной
модели работы, где требуется строгий контроль версий и доступ к истории изменений через сервер.
