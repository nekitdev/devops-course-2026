# Удобные вещи для работы с Git внутри IDE

1. Просмотр изменений в файлах — удобнее, чем в терминале (GUI vs TUI)
2. Сравнение веток — более наглядно, чем в терминале (с помощью графа)
3. Разрешение конфликтов — менее муторно по сравнению с консолью

## Что все же лучше делать в терминале

- Интерактивный `rebase` требует глубокого взаимодействия с терминалом
